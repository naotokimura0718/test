# Skill: biz-plan - 事業計画策定・更新

## 概要
年度・四半期の事業計画を策定・更新する。ベンチャーCEOが投資家・社内向けに使える実践的な計画を作成。

## トリガー
事業計画、ビジネスプラン、PL計画、売上計画の策定・更新を依頼された場合。

## 入力情報（ユーザーに確認する項目）
- 計画期間（年度/四半期/月次）
- 現在の売上・利益実績
- チーム人数・月次固定費
- 既存案件の見込み売上
- 営業パイプラインの状況
- 成長目標・資金調達状況

## 出力内容

### 1. PL計画（損益シミュレーション）
```

|---|---|---|---|---|---|---|
| 売上 | | | | | | |

| ├ パイプライン（確度別）| | | | | | |
| └ 新規見込み | | | | | | |
| 売上原価 | | | | | | |
| ├ エンジニア人件費 | | | | | | |

```

### 2. 売上の前提条件
- 案件単価の平均想定
- 月間稼働人数と稼働率
- 新規受注の想定ペース（月X件）
- 案件の平均期間・リピート率

### 3. シナリオ分析
- **楽観**: パイプライン全件受注、リピート率高
- **標準**: 受注確度に基づく加重平均
- **悲観**: 新規受注停滞、既存案件のみ

### 4. アクションプラン
- 売上目標達成に必要な営業活動量
- 採用計画（売上に対する人員キャパ）
- 投資判断（ツール導入、マーケティング等）

## 注意事項
- 受託開発は人月商売のため、稼働率が最重要指標
- キャッシュフローは売掛金の回収サイクルを必ず考慮
- ベンチャーは3ヶ月先の見通しが立てば十分。過度に長期の精緻な計画より、短期の精度を重視
